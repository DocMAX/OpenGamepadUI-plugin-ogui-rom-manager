OpenGamepadUI ROM Manager Plugin

This repository contains a plugin for OpenGamepadUI that aims to replicate the functionality of Steam ROM Manager. The plugin allows users to configure and manage parsers for ROMs and emulators, enabling the organization and launching of retro games directly within OpenGamepadUI. It provides a user-friendly interface to define parser settings such as names, executable paths, search globs, and directories, mimicking the ROM parsing and management capabilities found in Steam ROM Manager.
